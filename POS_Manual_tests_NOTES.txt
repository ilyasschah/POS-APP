[37] DONE - POS SESSIONS ARE LIVE. Sales now require an open session.

     WHAT CHANGED FOR THE CASHIER:
     Opening the POS with no session shows a screen with one button:
     OPEN REGISTER. Enter the starting cash, and selling begins.
     At the end: CLOSE REGISTER -> count the drawer -> the Z-report
     is generated for that session only.

     IF SOMETHING GOES WRONG - READ THIS FIRST:
     Settings -> Sync -> "Require an open session to sell".
     Turn it OFF and the till sells again immediately. That switch
     exists precisely so a bad session can never close your shop.
     Send me the session and I will fix it properly afterwards.

     The block is also DELIBERATELY forgiving: if the app cannot work
     out the session state (still loading, a database hiccup), it
     LETS THE SALE THROUGH rather than stopping you. It only blocks
     when it is certain there is no open session.

     HOW TO TEST:
     (a) Close the session, then open the POS -> the block screen
         appears with Open Register. Not an error, not an empty grid.
     (b) Open a register -> selling works normally.
     (c) Start closing (Close Register), then try to sell from
         another screen -> refused, because the drawer is being
         counted and a sale would change the number you are signing.
     (d) With no session: try a REFUND and a CASH IN/OUT -> both
         refused with the same offer to open the register.
     (e) Turn the setting off -> everything sells with no session.
         Turn it back on -> blocked again.
