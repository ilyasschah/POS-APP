SCREENSHOTS FOR THE HELP CENTRE (/help)
=======================================

Every guide on the help page can show ONE screenshot. Take the screens below,
save each one with EXACTLY the file name given, and put it in:

    website/public/help/

The help page shows a picture only for guides that have one. A guide without
a screenshot shows no picture and no placeholder, so you can add them one at
a time, in any order.

[x] = already done      [ ] = still to take
Priority: 1 = take first, 2 = next, 3 = nice to have


HOW TO TAKE THEM
----------------
- App in ENGLISH, LIGHT theme, the default BLUE accent colour.
  (If you take one in French or Arabic, say so when wiring it in, so the
  caption says "shown in French".)

- Wide screens: keep the window about 1280 x 800 so text stays readable.
- PNG only. File names are lowercase with dashes, exactly as written below.


WHEN THE FILES ARE IN THE FOLDER
--------------------------------
Easiest: tell Claude "wire the new help screenshots". It adds each file to
its guide in all three languages.

By hand: open website/app/help/content.ts, find the guide by its id (listed
below as "guide id"), and add a shot entry to that guide in EACH of the three
language blocks (en, fr, ar):

    shot: {
      src: "/help/sale-screen.png",
      width: 1280,    <- the image's width in pixels
      height: 800,    <- the image's height in pixels
      alt: "What the picture shows, for screen readers.",
      caption: "Short caption shown under the picture.",
    },

(To find width and height: right-click the file > Properties > Details.)
Then rebuild the site: npm run build
